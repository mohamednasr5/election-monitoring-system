# Installation Guide - دليل التثبيت

## English

### Quick Start
1. Download both files:
   - `election-input.html` - Voter registration and voting form
   - `statistics.html` - Live statistics dashboard
   - `candidates.json` - Candidates data (optional)

2. Open files in your browser:
   - Use a modern browser (Chrome, Firefox, Edge)
   - No server required - runs completely client-side

3. Login with password: **521988**

### Requirements
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (for Firebase sync)
- No installation needed - just open HTML files

### Firebase Setup
The system uses Firebase Realtime Database. Update Firebase config in both HTML files:
- Replace `apiKey` with your Firebase project key
- Replace `databaseURL` with your Firebase URL
- Replace `projectId` with your project ID
