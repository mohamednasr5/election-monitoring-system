# System Features

## Input Form Page
- Voter registration with automatic time recording
- Select 2 out of 15 candidates
- Vote validity marking (Valid/Invalid)
- Password protection (521988)
- Confirmation before submission
- Duplicate name warning
- Real-time validation
- Responsive mobile design

## Statistics Dashboard
- Live real-time updates (every 6 seconds)
- Interactive bar chart visualization
- Vote counts per candidate
- Percentage distribution display
- Average votes per minute calculation
- Filter votes (All/Valid/Invalid)
- Export to Excel/CSV
- Current time display
- Password protected access

## Technical Features
- Firebase Realtime Database
- ES6 Module-based JavaScript
- Modern CSS3 with gradients
- RTL Arabic support
- Chart.js for visualization
- No server required
- Completely client-side processing
- Automatic data sync

## Security
- Password protection (521988)
- Secure Firebase configuration
- Client-side validation
- No sensitive data in URLs
